# Popup template assets

These images were supplied from the user's current Shop Titans build.
They are grouped by semantic popup type rather than by exact wording or price.

- `reconnect/`: Error 1000 and Error 4006 layouts
- `paid_offer/`: Limited Time and Naya paid offer layouts
- `upgrade_finished/`: two COMPLETE-banner variants

The current detector accepts multiple variants for one `PopupType`. Runtime code
must never depend on a specific error number, offer price, or promotional title.
